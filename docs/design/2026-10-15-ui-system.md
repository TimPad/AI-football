## Набор концепций и происхождение

Концепции созданы встроенным Image Gen, режим `ui-mockup`, с синтетическими командами/игроками. Они показаны в разговоре отдельно, крупными экранами; локальные PNG сохраняются вне Git. Это референсы будущей реализации, не скриншоты работающего приложения. Все тексты, поля, таблицы и SVG-площадки будут кодовыми.

| Ключ | Экран | Ключевой сценарий |
|---|---|---|
| `public-match` | Статистика матча + открытый инспектор игрока | Две карты на общей шкале, таблица, факты выбранного издания, отдельный переход к текущему CV |
| `calendar` | Матчи турнира, сетка времени и залов | Фильтр дня/зала/статуса, список/сетка, создание и открытие матча |
| `review` | Админ+, проверка личности | Очередь материала → доказательство → назначение UUID → сохранение |
| `publication` | Публикация матча | Протокол, CV, разрешения и рейтинг публикуются независимо; справа текущий гостевой результат |

Проверенное состояние набора: `public-match` и `calendar` исправлены повторной генерацией. `review` и `publication` сохранены как **черновики с обязательными правками**, а не готовая спецификация реализации: повторные попытки Image Gen завершились сетевой ошибкой. Пользователь пока не утверждал ни одно изображение.

В первых генерациях появились незаказанные xG, вклад рейтингов от перемещений и конфликтующие команды в расписании; эти ошибки исправлены. В административных черновиках ещё нужно убрать тактическую схему/вымышленный прогресс из preview, транспорт видеоплеера из проверки, случайный логотип-мяч, привести даты и акцент к остальным экранам. Обязательные корректные состояния перечислены ниже. Эти детали не разрешают добавлять соответствующие функции в продукт.

## Brief генерации

Полный читаемый desktop-экран, ориентир1600×1000, без рамки устройства/коллажа. Русский продукт AI Football для футзала: компактная шапка матча, широкая рабочая область, светлая нейтральная оболочка, тёмные площадки/медиа, один лаймовый акцент. Отступы24px, тонкие разделители, спокойная типографика14–16px с табличными цифрами. Никакой рекламы, ставок, маркетингового hero, декоративных KPI, личных фото или вымышленных функций. Инициалы команд вместо новых брендовых логотипов. Надпись «Демонстрационные данные» обязательна.

Для `public-match`: вкладки «Обзор / События / Игроки / Статистика / Видео», две несглаженные CV-карты с легендой секунд, реальные категории показателей, справа игрок/роль/оценка/полнота. Для исторической оценки карта не подменяется текущей; доступен явный переход к текущему CV. Никакого xG и вклада физической работы в оценку.

Для `calendar`: турнирная навигация, сетка «время × зал», два зала, четыре синтетических матча без одновременного участия одной команды в двух залах. Границы слотов соответствуют времени. Непроведённый матч не показывает0:0.

Для `review`: три панели — очередь240px, материал≥420px, инспектор300px; номер только подсказка, UUID назначается явно. Dirty блокирует подтверждение; никаких процентов удалённой обработки. Генерированный кадр только в концепции: реальный UI при отсутствии evidence показывает пустое состояние.

Для `publication`: отдельные строки протокола/CV/разрешений, отдельный турнирный расчёт и publish. Справа только опубликованные значения, без вымышленной стартовой расстановки, траекторий или командной таблицы турнира. Нет кнопки «опубликовать всё».

## Токены и типографика

Предложенные значения уточняются по принятому изображению до CSS; числовые размеры из согласованной спецификации остаются обязательными. Лайм обозначает выбор/основное действие; успех/ошибка имеют собственный текст и иконку.

| Токен | Значение | Использование |
|---|---|---|
| `--app-bg` | `#f4f6f8` | Холодный нейтральный фон |
| `--surface` | `#ffffff` | Белая поверхность |
| `--text` | `#19221f` | Основной текст |
| `--text-muted` | `#697487` | Вторичные подписи |
| `--border` | `#e2e7ec` | Разделитель/контрол |
| `--accent` | `#b8ec64` | Основная кнопка/выбор |
| `--accent-soft` | `#eef8dc` | Выбранная строка/пункт |
| `--pitch` | `#172620` | Площадка/медиа |
| `--home` / `--away` | `#488ee6` / `#e9aa49` | Сравнение команд, независимо от статуса |
| `--radius` | `8px` | Контролы и медиа |
| `--space` | `4,8,12,16,24,32px` | Ритм и отступы |
| `--focus` | `2px solid #3479ce`, offset2px | Клавиатурный фокус |

Шрифт: существующий доступный sans-serif стек с кириллицей; без новой внешней зависимости. Основной текст16px/24, компактные контролы/таблицы14px/20, подписи12–13px/18, заголовки20px/28 и28px/36. Иерархия согласуется с концептами; не использовать случайные browser-default размеры. Числа `font-variant-numeric:tabular-nums`.

Сетка public max1440px с полями24–32px; панель игрока440–520px. Cabinet rail224px. При1440 review три области240/≥420/300; при1024–1439 очередь открывается кнопкой. При390 таблицы прокручиваются локально, inspector становится доступным диалогом, материал/инспектор открываются последовательно. Ширины в растровых изображениях приблизительны: точная реализация использует эти размеры из spec; не копировать случайный размер рейла по пикселям генерации.

## Компоненты и состояния

| Семейство | Варианты/поведение |
|---|---|
| Кнопка | primary lime, secondary white, text link, pending с текстом действия, disabled с объяснением рядом |
| Навигация | Глобальная шапка, сгруппированный rail, одна линия задач матча, active underline/фон и `aria-current` |
| Строка/таблица | Тонкий разделитель, hover, selected с мягким lime; ссылки имеют видимый focus |
| Источник | Название, версия/длительность, раскрытие технических ID; статус не только цвет |
| Карта | Тёмное поле фактической геометрии, несглаженные ячейки секунд, нулевые прозрачны, внешняя числовая легенда |
| Inspector | Имя/номер выбранного источника, закрытие, источник роли/оценки, факты/неизвестность; Escape и возврат фокуса |
| Ошибка | Внутри затронутого блока, retry, работающие блоки остаются |
| Пустой источник | «Протокол ещё не опубликован» / «Нет наблюдений» / «Карта этого издания недоступна»; неизвестность не0 |
| Черновик | Видимый dirty/pending, повтор той же команды;409 не стирает ввод; raw-download повреждённого ввода |
| Публикация | Каждая строка имеет собственные текущую/выбранную версии, blocker/fix link, независимое действие |

Иконки: существующий lucide-react, outline20px, stroke1.75–2, без собственного цветного контейнера на каждом пункте. Calendar, Trophy, Users, UserRound, MapPin, FileText, Video, Upload, ChevronDown, ArrowLeft/Right, ExternalLink, X и CircleAlert/Check используются по смыслу. Не заменять карту поля иконкой географической карты; empty-state без декоративной иллюстрации допустим. Motion120–180ms для открытия/hover; `prefers-reduced-motion` отключает переходы.

## Тексты, данные и обязательные уточнения реализации

Публичные вкладки: «Обзор», «События», «Игроки», «Статистика», «Видео». Категории: «Удары», «Передачи», «Защита», «Вратари», «Перемещения». Показатели из saved facts, неизвестное — «Нет данных». «18 / 23 · 78%» сопровождается отдельным количеством неопределённых исходов;0/0 не процент0. Причины оценки — только сохранённое explanation, не придуманные генерацией положительные пункты.

Рабочие задачи: «Обзор», «Состав», «Протокол», «Проверка», «Участие», «Действия», «Отчёт», «Публикация»; «Сведения» и «История» доступны дополнительными пунктами. «Работа» — заголовок группы, не дополнительная страница.

Режимы: «Вести матч», «Заполнить после матча», «Только итог». CV: «Результат не загружен», «На проверке», «Подтверждён», независимые active/published отметки. «Сохранить назначение» не подтверждает всю версию. «Подтвердить версию» блокируется при dirty.

Публикация: «Опубликовать протокол», «Опубликовать CV», «Сохранить разрешение», «Пересчитать рейтинг», «Опубликовать издание». Подпись preview: «Сейчас видит зритель», только public DTO. Участие и действия — select текущих разрешённых версий, не декоративные status cards.

Геометрия/единицы/данные имеют приоритет над ошибочной надписью генерации: темп движения из контракта — м/мин; «Обработанный фрагмент» не «Весь матч» для partial; карта секунд не карта касаний. Площадка рисуется SVG, без GPS. Статистика перемещений не влияет на оценку. Числа на концептах только пример композиции: реальные числа никогда не вшиваются в экран. На календарной шкале30/60/90 минут должны иметь пропорциональные интервалы и совпадать с границами слотов.

После пользовательской проверки записать принятую версию и только затем пометить design lock. До этого никакой концепт не объявляется утверждённым, а Task1 плана остаётся частично открытой.
