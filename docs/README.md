## Архитектура и следующие этапы

- [Итоговая HTML-архитектура сервиса](architecture/2026-10-14-final-service.html): интерактивные представления всего сервиса, пути матча, оценок/турнира и локального/облачного развёртывания; статусы разделяют реализацию и план. Откройте HTML в браузере; внешние скрипты не нужны.
- [YOLO + Qwen3.8-Omni-Flash](superpowers/specs/2026-10-14-qwen-match-understanding-design.md): спецификация локальной проверки номеров и эпизодов, восстановления и последующего переноса на прерываемую GPU-ВМ; код локального пути реализован; live API и спортивная точность пока не проверены.
- [План локальной реализации Qwen](superpowers/plans/2026-10-14-qwen-match-understanding.md): API, клипы со звуком, восстановление, результат версии 2, кабинет и приёмка; реализованы CV resume, API-клиент, результат v2 и закрытый кабинет; фактическая приёмка описана отдельно.
- [Оценки и метрики турнира](superpowers/specs/2026-10-14-player-ratings-tournament-design.md): исследование публичных ведущих методик, футзальные позиции, формулы/полнота и последующие xG/xT/VAEP.
- [План оценок и рейтингов](superpowers/plans/2026-10-14-player-ratings-tournament.md): участие/действия, матчевые оценки, общий/позиционные рейтинги, турнирные срезы и публикация; локальная реализация проверена на synthetic, спортивная калибровка впереди.
- [HTML-схема](architecture/2026-10-13-video-analytics.html): скачайте файл и откройте в браузере; на GitHub отображается исходный HTML.
- [Контракт внешней обработки](specs/2026-10-13-external-processing-and-report-import.md).
- [План внедрения](superpowers/plans/2026-10-13-video-analytics-import.md): первая поставка выполнена; вторая и третья — план.
- [Модель аналитики игрока](specs/2026-10-13-player-match-analytics-design.md).
- [Варианты хранения и вычислений](specs/2026-10-13-video-upload-and-workers-options.md): проектные предложения, а не настроенная инфраструктура.
