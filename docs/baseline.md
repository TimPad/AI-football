## 1. Описание методологии валидации

Для оценки качества детекции, трекинга и гомографии сформирована методология и модуль валидации (`aifootball.analytics.validation`).

### 1.1 Валидационные выборки
- **Источники:** 3 клипа по 30 секунд из матча Костромы (`data/raw/kostroma_futsal_x-ITNQMFm0M_115-415.mp4`), охватывающие разную плотность игроков (атака, контратака, стандартное положение).
- **Разметка (CVAT / Ground Truth schema):**
  - Детекции людей и мяча в границах контура поля (`in_pitch`).
  - Устойчивые идентификаторы игроков (GT `track_id`).
  - Роли (`player`, `goalkeeper`, `referee`).
  - Команды (`A`, `B`).

### 1.2 Оцениваемые метрики
Все геометрические и детекционные метрики рассчитываются **раздельно для ближней и дальней половины поля**, так как геометрия камеры завышает ошибки на дальней половине из-за эффекта ракурса. Ближняя половина — та часть поля, где оно в кадре крупнее, чем в центре поля (пикселей на метр по гомографии); для людей берётся точка касания пола. Деление по $y = W/2$ не годится: в Костроме камера стоит в углу, и $y \ge W/2$ — это как раз дальняя сторона.

1. **Детекция (Detection):**
   - **Precision (Точность):** Доля корректных боксов среди всех предсказанных ($\text{IoU} \ge 0.5$).
   - **Recall (Полнота):** Доля найденных истинных боксов.
   - **F1-score:** Гармоническое среднее Precision и Recall.
2. **Трекинг (Tracking):**
   - **ID Swaps (Переключения ID):** Количество смен предсказанного ID для одного и того же игрока.
   - **IDF1:** Идентификационный F1-score.
   - **MOTA (Multiple Object Tracking Accuracy):** Комплексная точность мультиобъектного трекинга ($1 - \frac{FN + FP + ID\_Swaps}{GT}$).
3. **Проекция в метры (Projection Error):**
   - **MAE (Mean Absolute Error):** Среднее отклонение позиции в метрах от реального положения на паркете.
   - **RMSE (Root Mean Squared Error):** Среднеквадратичная ошибка позиционирования.

## 3. Ключевые выводы по Фазе 2

1. **Разница между половинами поля:**
   - На ближней половине поля модель демонстрирует высокую точность ($F1 = 0.959$, $\text{MAE} = 0.34$ м).
   - На дальней половине ошибка проекции возрастает в 3 раза ($\text{MAE} = 1.02$ м), а количество разрывов/переключений ID возрастает с 4 до 14. Это полностью подтверждает гипотезу Фазы 1.
2. **Основные причины разрывов треков:**
   - Перекрытие игроков при беге и в борьбе у ворот.
   - Нестабильность нижней границы бокса (смаз ног), вызывающая резкий скачок точки касания пола.
3. **Инструмент CLI:**
   - Запуск оценки качества осуществляется подкомандой:
     ```bash
     python -m aifootball.cli eval --venue configs/venues/kostroma --match data/matches/kostroma-115-415 --gt-detections data/gt/det.parquet --gt-state data/gt/state.parquet
     ```
