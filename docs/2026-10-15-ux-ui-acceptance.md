## Что реализовано

| Задача | Результат |
|---|---|
| 1. Визуальная система | Design lock 15.10: PNG `public-match`, `calendar` с письменными правками + HTML-прототипы `review` и `publication` (вне Git, `output/ux-prototypes`) |
| 2. Публичная шапка | `PublicMatch.home/away_team_id`, `home/away_logo_id`; `GET /public/catalog/team-logos/{id}` — только логотип команды неархивного турнира, не фото игрока, `no-store`, `nosniff` |
| 3. Чтение публикации | `GET /matches/{id}/performance-publication` (Админ+): ревизия `TournamentRatingState` или 0, выбранные версии; без INSERT/UPDATE/DELETE |
| 4. Модель отчёта | Отдельные указатели протокола/CV/рейтинга, соединение игроков по UUID, карта секунд на общей шкале без сглаживания, «Обработанный фрагмент» |
| 5. Оболочки | Токены и контролы; кабинет: рейл 224 px, верхняя панель; сайт: ширина до 1440 px; URL-контекст и доступная панель игрока |
| 6. Гостевой матч | «Обзор / События / Игроки / Статистика / Видео», только `/public/*`, независимые ошибки блоков, карточка игрока с изданием, история оценок `/watch/players/:id` |
| 7. Турнир | Календарь «время × зал» с пропорциональной шкалой и дорожками пересечений, фильтры в URL; рейл «Работа / Участники и площадки / Настройки» |
| 8. Кабинет матча | Задачи одной навигацией; одна очередь протокола на редактирующие задачи; режим «Только итог» без фиктивных событий/полноты |
| 9. Проверка CV | Статус задания по его импортам; три панели 240 / ≥420 / 300, фильтр и страницы только меняют видимость, полный PUT; фильтр эпизодов по решению |
| 10. Публикация | Отдельные строки протокола, CV, источников оценок и рейтинга турнира; «Сейчас видит зритель» только из публичных маршрутов; очередь протокола создаётся только по нажатию |

## Изменения контрактов для тестов и ссылок

Вкладки турнира и матча стали ссылками (`?tab=`), задачи матча — навигация «Задачи матча». Карточки расписания открываются ссылкой «Открыть матч …». Публичный рейтинг турнира — `/watch/tournaments/:id?tab=ratings`, CV-статистика матча — `?tab=stats`. Старые `/matches/:id` и `?tab=analysis|video` продолжают работать (переход на «Проверку»). E2E-помощники обновлены.

## Ограничения

- Историческая оценка не получает текущую CV-карту: публичный API не выдаёт архивные карты. Текущую карту можно открыть явно.
- Командное сравнение строится только из сохранённых командных агрегатов CV; синтетический импорт E2E их не содержит, поэтому там карты команд честно показаны как недоступные.
- Отчёт в кабинете показывает опубликованный протокол, активную версию CV и последний частный срез оценок; это не гостевая ссылка.
- CLI `report.html` остаётся отдельным техническим экспортом со старым оформлением.
- OCR, маски, Connected Processor, S3, GPU и живой Qwen не проверялись и не объявляются готовыми.
- Все автоматические проверки используют синтетические данные; демонстрационная запись не использовалась.
- Независимое ревью выполнено исполнителем по пяти пунктам Review Focus плана. Отдельный агент-ревьюер не запускался; при необходимости — `/code-review`.
